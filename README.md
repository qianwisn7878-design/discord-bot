# ETG 커뮤니티 봇

홈페이지와 같은 API·계정·권한·포인트·참가 명단을 사용하는 Discord 봇입니다.

- `/etg`: 상점, 포인트, 잡상인, 모집, 일정, 공지, 지원서, 프로필, 발로란트 계정, 알림, 내전, 서버 관리
- `/etg파일등록`: 기프티콘·상품 이미지, 확률 설정, 긴 게시물 JSON 등록
- `/내전`: 기존 내전 신청 메뉴

Node.js 22.12 이상, 실행 파일 index.js. 디스호스트 GitHub 자동 배포를 사용하며 .env는 비공개 호스팅 설정으로 유지합니다.

[설정과 테스트 안내](TESTING.md)를 참고하세요.

## 신고 · 문의 · 건의 티켓

카테고리 `1564911577017360465`에 `티켓-접수` 드롭다운을 자동 설치합니다. 티켓 채널은 같은 카테고리에 비공개로 생성됩니다. 닫으면 읽기 전용으로 보관하고, 다시 열 수 있습니다. 영구 삭제는 전체 총관리자 본인 계정과 커뮤니티 `Sub Admin`만 가능합니다. 다른 Admin·Moderator·Helper는 삭제할 수 없습니다. 삭제 직전에 실제 역할을 다시 검사하며 확인 버튼이 필요합니다.

GitHub 최신 코드로 디스호스트를 배포하면 자동 설치됩니다. 추가 환경변수나 패키지는 필요 없습니다.

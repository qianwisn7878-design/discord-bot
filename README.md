# ETG 내전 신청 봇

ETG 홈페이지의 내전 공지·참가·예약·취소와 가위바위보·맵 밴픽·공수 선택을 Discord와 연동합니다. `/내전` 명령으로 목록을 확인합니다.

## 디스호스트

1. NodeJS 봇을 생성합니다. Node.js 22.12 이상(가능하면 24 LTS)을 사용합니다.
2. 저장소 소스를 파일 매니저에 올립니다. `index.js`, `bot.mjs`, `bridge.mjs`, `package.json`, `package-lock.json`이 실행 폴더 바로 아래에 있어야 합니다. `node_modules`는 올리지 않아도 됩니다.
3. 시작 파일은 **index.js**로 설정합니다. 패키지 설치는 호스팅 설정에 따라 자동 설치하거나 `npm ci --omit=dev --omit=optional`을 실행합니다.
4. 아래 환경 변수를 호스팅의 비공개 설정에 등록하거나 실행 폴더의 `.env` 파일에 넣습니다.
5. 시작을 누릅니다. `온라인`과 `참가 접수 준비 완료`를 확인합니다.

## 필요한 비공개 설정

- DISCORD_BOT_TOKEN: 현재 홈페이지와 동일한 봇의 토큰
- DISCORD_CLIENT_ID: 1550151990900686939
- ETG_SITE_URL: https://enjoythegame.craftyamber8.chatgpt.site
- ETG_SITE_ACCESS_TOKEN: 홈페이지 접속용 서비스 키
- ETG_BRIDGE_SECRET: 홈페이지와 봇의 연동 서명 키

`.env.example`은 빈 양식이며 실제 비밀값은 포함하지 않습니다. 실제 `.env`는 GitHub에 올리지 마세요. 기존 PC용 설정 파일을 받았다면 그대로 사용 가능합니다. 홈페이지의 봇 설정 메뉴는 사용자의 요청으로 제거되었으므로 해당 메뉴가 다시 보인다고 가정하지 않습니다.

## 동작 및 관리

- 새 내전은 커뮤니티 공지 채널 1560701291427135698에 게시됩니다.
- 신청에는 홈페이지에 연동된 발로란트 계정이 필요합니다. 같은 사용자 ID의 명단을 사용합니다.
- 메시지 내용 읽기 인텐트는 필요하지 않습니다. 봇은 세 ETG 서버에 가입되어 있어야 합니다.
- 봇은 분당 한 번 연결 상태와 실패했던 공지를 확인합니다.
- 같은 토큰의 PC 봇은 종료하고 호스팅에서 한 번만 실행하세요.
- GitHub 코드를 수정했다고 호스팅이 자동 반영되는 것은 아닙니다. 디스호스트의 GitHub 배포 연동을 설정했을 때만 자동 반영되며, 그렇지 않으면 수정 파일 업로드 후 재시작합니다.
- 홈페이지 DM·음성방 기능은 별도로 동작합니다.

## 로컬 확인

Node.js 22.12 이상에서 `npm ci`, `npm test`, `npm start`를 사용합니다.

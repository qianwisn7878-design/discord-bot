# 프리미어 가입·전화번호·동의 표시 역할

서버 도우미 봇을 최신 코드로 업데이트하고 재시작하면 적용됩니다. 홈페이지나 내전봇 코드는 변경할 필요가 없습니다.

## 전화번호

프리미어 서버에 `전화번호 입력`, `전화번호 미입력` 역할을 권한 없이 자동 생성합니다.
입장 기본 역할에 `전화번호 미입력`을 포함하고, 기존 인원도 시작 시 및 1분마다 확인합니다.
로컬 비공개 `legacy/data/userInfo.json`의 저장 값이 있으면 입력 역할, 비어 있거나 해당 사용자 기록이 없으면 미입력 역할로 전환합니다.
입력 버튼으로 저장한 직후에도 즉시 재확인합니다. 숫자 자체는 역할·공지·홈페이지 백업으로 전송하지 않습니다.
저장 파일 자체를 읽지 못한 경우에는 전체 인원을 미입력으로 단정하지 않고 오류를 기록하고 재시도합니다.

## 가입 승인과 팀원 자격

- 팀가입 승인: 커뮤니티 서버에 `발로란트 프리미어 팀` 역할이 있으면 승인. 프리미어 서버의 약관 동의와 독립적입니다.
- 프리미어 팀원: 커뮤니티 팀 역할, 이용약관 동의, 개인정보 동의, 전화번호 입력 조건을 모두 충족해야 합니다.
- 전화번호 입력 역할은 저장된 값으로 재확인하므로 역할만 수동으로 붙여서 자격 조건을 우회하지 않습니다.

## 동의 표시 역할 정리

모든 조건을 충족해 프리미어 팀원이 되면 아래 표시 역할을 제거합니다.

- 이용약관 동의 / 이용약관 미동의
- 개인정보 동의 / 개인정보 미동의
- 모든 약관 동의

전화번호 상태·팀가입 승인 역할은 별도로 유지합니다.
동의 상태는 기존 로컬 비공개 개인정보 파일의 해당 사용자 `premierConsent` 항목에 보관하므로 표시 역할 제거가 동의 철회로 취급되지 않습니다.

전화번호 삭제, 약관/개인정보 동의 철회, 커뮤니티 팀 역할 상실 중 하나라도 발생하면 팀원 역할을 회수하고, 저장된 실제 동의 상태에 맞는 동의 또는 미동의 표시 역할을 복원합니다. 동의·미동의 양쪽을 동시에 지급하지 않습니다.
약관 체크 반응을 제거하거나 다시 체크하는 기존 입력 방식은 유지됩니다. 재입장 시에는 프리미어 서버 동의 상태를 다시 확인하도록 미동의로 초기화합니다.

봇 역할은 위 상태 역할들보다 위에 있어야 하며 역할 관리 권한이 필요합니다.
기존 개인정보 파일은 계속 보존하고 호스팅 이전 시 비공개 백업으로 옮겨야 합니다. 이 파일은 GitHub에 올리지 않습니다.
